# Source Availability for Bundled SVN CLI

The bundled SVN command-line runtime was copied from a TortoiseSVN installation
and was not modified by CalcChain.

Upstream source locations:

- TortoiseSVN source documentation:
  https://tortoisesvn.net/docs/release/TortoiseSVN_en/tsvn-preface-source.html
- TortoiseSVN source browser:
  https://sourceforge.net/p/tortoisesvn/code/HEAD/tree/
- Apache Subversion project:
  https://subversion.apache.org/

If CalcChain is distributed publicly with these files, verify the exact
TortoiseSVN release version used for the bundle and provide either the matching
complete corresponding source or a compliant written offer/source location for
that exact release.
