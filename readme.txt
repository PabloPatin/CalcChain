CalcChain: как запустить программу
==================================

Корень проекта:

  D:\AI_Coding\CalcChain


Быстрый запуск на этом компьютере
---------------------------------

1. Открой папку проекта:

   D:\AI_Coding\CalcChain

2. Запусти файл:

   calcchain.bat

3. Дождись открытия браузера.

   Адрес локального интерфейса:

   http://127.0.0.1:8765/

Если браузер не открылся сам, открой этот адрес вручную.


Запуск для доступа с другого устройства в локальной сети
--------------------------------------------------------

1. Запусти файл:

   calcchain-lan.bat

2. В открывшемся окне будет показан адрес вида:

   https://<ip-адрес>:8443/

3. Открой этот адрес на другом устройстве в той же сети.

4. Введи pairing code, который показан в окне запуска.

Важно: HTTPS-сертификат самоподписанный, поэтому браузер может показать
предупреждение безопасности. Для локального запуска это ожидаемо.

Чтобы выдать новый pairing code без перезапуска LAN-режима, запусти:

  calcchain-lan-pair.bat


Как остановить CalcChain
------------------------

Запусти:

  calcchain-stop.bat

Он остановит backend и HTTPS-прокси, если они были запущены.


Где хранятся данные
-------------------

Пользовательские проекты:

  Документы\CalcChainProjects

Служебное состояние backend, логи и запуски:

  %LOCALAPPDATA%\CalcChain

Папки отдельных запусков через UI:

  %LOCALAPPDATA%\CalcChain\runs\<run_id>\job

Рабочая папка расчета внутри запуска:

  %LOCALAPPDATA%\CalcChain\runs\<run_id>\job\work

Логи backend:

  %LOCALAPPDATA%\CalcChain\logs


Пример расчета из репозитория
-----------------------------

В проекте есть готовый пример:

  examples\two_local_sources_import

Он показывает сценарий:

  два локальных источника файлов + код -> расчет -> импорт результатов в другую папку

Запуск примера из корня проекта:

  python examples\two_local_sources_import\run_demo.py

После запуска результаты будут здесь:

  examples\two_local_sources_import\imported_results

Рабочая папка расчета примера будет здесь:

  examples\two_local_sources_import\job\work

Инструкция по сборке этого же сценария через ноды:

  examples\two_local_sources_import\NODE_GRAPH_INSTRUCTIONS.txt


Если запуск не работает
-----------------------

1. Проверь, что порт 8765 свободен.

2. Останови старый запуск:

   calcchain-stop.bat

3. Запусти снова:

   calcchain.bat

4. Если ошибка остается, посмотри логи:

   %LOCALAPPDATA%\CalcChain\logs
